# AGENTS.md

Instructions for coding agents (Codex, Claude, and others) working in this repository.

## Date-time stamp requirement

Owner rule, adopted 2026-10-12 05:31 UTC. Every document you create or update must show:

- **Version:** `v1`, `v2`, …, increased on every substantive change.
- **Issued / updated:** `YYYY-MM-DD HH:MM UTC`, taken from the system clock
  (`date -u '+%Y-%m-%d %H:%M UTC'`). Never estimate it.
- **Prepared by:** who wrote it and who it was prepared for.
- **Revision history** at the end: version, UTC time, and what changed. Add a row each time; never
  edit or delete past rows.

This covers notes, handoffs, plans, reports, decision records, meeting notes, and session summaries.
Commits, pull requests, and code files are exempt. Full standard:
`.claude/rules/date-time-stamps.md`.
